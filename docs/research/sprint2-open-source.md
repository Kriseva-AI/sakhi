# Sprint 2 open source reuse research

Research date: 2026-10-19. Scope: preventive learning plus support after a concern, a richer minimal responsive interface, and community participation. This is a research recommendation. No dependency was installed, code changed, integration enabled, account accessed, or service contacted.

Keep the existing Vite, React, FastAPI and SQLite foundation. The strongest additions are selective accessible primitives, locally served script fonts, and real HSDS validation. Build Sakhi's routing, consent boundaries and public content workflow directly because a general library cannot supply its safety policy. Maps, messaging and a private vault remain separate gated capabilities.

## What already exists

The inspected checkout has React 19.2, strict TypeScript, Vite, Lucide, Python 3.11+, FastAPI/Pydantic, an in-memory SQLite FTS5/BM25 router, optional Python sentence-transformers, 16 draft locale catalogs and explicit English safety fallback. It has deterministic emergency and supported minor routes, a destination preview, synthetic action blocking, session erase with pending-request invalidation, public-only service-worker caching, stale generic fallbacks, and read-only maintenance. These are foundations to extend, not proposed new accomplishments.

The directory contains 211 discovery leads and seven preview-curated public entry points. Human production approvals, individual OSC records and provider integrations are zero. The export is explicitly HSDS-inspired, not validated conformance. Fonts currently come from the operating system. There is no installed map, messaging SDK, private vault, speech engine or generative advice model. Playwright, axe and Vitest are already present.

Local evidence: [architecture decision](../ADRs/001-local-architecture.md), [data provenance](../DATA_PROVENANCE.md), [release gates](../RELEASE_GATES.md), [model benchmark](../evidence/model-benchmark.json), [frontend dependencies](../../package.json), [Python dependencies](../../pyproject.toml), [font tokens](../../apps/web/src/tokens.css), and [disabled adapter](../../services/api/adapters.py).

## Build versus reuse decisions

| Area | Best fit | Decision and compatibility | Boundary |
| --- | --- | --- | --- |
| Rich accessible controls | [Adobe React Aria](https://github.com/adobe/react-spectrum) | Adopt selectively for a complex combobox, sheet, disclosure group or comparison view. Its released package accepts React 19. Preserve Sakhi's visual tokens and native simple controls. | Built-in focus and keyboard behavior still need device testing. Its documented locale inventory does not cover all Sakhi languages. Do not claim translated widget announcements are complete. |
| Alternative UI foundation | [Radix Primitives](https://github.com/radix-ui/primitives) | Valid MIT alternative if a measured component spike is smaller or easier. Choose one primitive system. | Installing both systems or importing a large dashboard template adds inconsistency without solving the support journey. |
| Indic typography | [Noto Devanagari](https://github.com/notofonts/devanagari), [Noto Nastaliq](https://github.com/notofonts/nastaliq) and per-family [Google Fonts sources](https://github.com/google/fonts) | Add reviewed, self-hosted WOFF2 assets by script. Retain OFL notices. Devanagari serves several current locales; each remaining script needs its own checked family. | An Urdu font does not prove Kashmiri coverage. Check shaping, diacritics, line height, clipping, 400 percent zoom and cold-load layout. Avoid Google Fonts CDN requests from support pages. |
| Localization | Existing catalogs; [react-i18next](https://github.com/i18next/react-i18next) when complexity warrants it | Keep current explicit review status and fallback. Consider i18next for pluralization, namespaces and contributor tooling when reviewed learning modules grow. Compatible peer ranges include current React/TypeScript. | No automatic language detection, translation cloud, remote backend or missing-key reporting containing user input. A localization engine does not review translations. |
| Local retrieval | Existing SQLite; [MiniSearch](https://github.com/lucaong/minisearch) for a bounded browser spike | Retain FTS5 as the reference. MiniSearch is dependency-free, browser-capable public-document search, useful if the learning library grows beyond the seven records. Evaluate before adding it. | Search only curated public text in memory. Test Indic tokenization and romanized queries. Its scoring is not assumed equivalent to SQLite BM25. Never index stories, age answers or local drafts. |
| Public directory interoperability | [Open Referral HSDS](https://github.com/openreferral/specification) | Pin schema v3.3.1 and validate an actual organization/service/phone export. Keep source permissions and review metadata in an explicit Sakhi profile or sidecar. Build the curation queue. | The specification is CC BY-SA 4.0. Retain attribution and review copied schema adaptations separately from Apache code. HSDS describes data; it supplies neither Indian providers nor proof of current availability. |
| On-device privacy | Current non-persistence; native [Web Crypto](https://www.w3.org/TR/webcrypto/) for a future reviewed vault | Keep T0 free of private storage. [noble-ciphers](https://github.com/paulmillr/noble-ciphers) is a possible primitive library only when a reviewed design needs an unavailable native primitive. | Neither supplies a safe recovery, deletion or coercion model. Do not add encrypted IndexedDB as a cosmetic privacy feature. JavaScript cannot promise forensic erasure or protection from a compromised browser. |
| Coarse service discovery | List first; optional [Leaflet](https://github.com/Leaflet/Leaflet) | Prefer a district-filtered, keyboard-accessible list of individually sourced records. Consider Leaflet only after real directory coverage exists. | No GPS request, route history or safety prediction. Tile hosting, attribution, lawful reuse and offline distribution are separate obligations. [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js) is an alternative for a justified vector-map need, with greater rendering and asset complexity. |
| Optional consented messaging | Existing preview; future [Matrix JS SDK](https://github.com/matrix-org/matrix-js-sdk) | Keep adapters disabled. Matrix is worth a future partner-controlled feasibility study, not a Sprint 2 default. Node 22 matches the SDK requirement. | A homeserver, authenticated provider, staffed service, retention policy and explicit per-action consent are prerequisites. Rust crypto initialization defaults to IndexedDB, with an unencrypted store unless a storage key/password is supplied. Transport encryption does not remove metadata or device risk. |
| Evaluation and security | Existing [Playwright](https://github.com/microsoft/playwright) and [axe-core](https://github.com/dequelabs/axe-core); [OWASP ASVS](https://github.com/OWASP/ASVS) | Expand current tests rather than replace them. Use stable ASVS 5.0.0 as a control reference. Keep test narratives synthetic. | Automated axe success is partial accessibility evidence. Screen readers, language comprehension and safeguarding require human assessment. Do not adopt a moving ASVS `latest` artifact as the pinned release. |
| Public-benefit design and contribution | [Chayn Bloom frontend](https://github.com/chaynHQ/bloom-frontend) | Study its self-paced support patterns, contribution process and separation of service choices. Reuse small MIT code fragments only after review and attribution. | Its package lists Next.js, Firebase, Hotjar, Rollbar, New Relic, CMS and external service dependencies. That stack is not a drop-in match for anonymous offline T0. Code licensing does not automatically settle rights to every course, image or linked resource. |

React Aria's [quality guidance](https://react-aria.adobe.com/quality) explains focus, RTL, labels and its locale list. The [released package manifest](https://github.com/adobe/react-spectrum/blob/react-aria-components%401.22.0/packages/react-aria-components/package.json) supplies the React peer range. Matrix's [crypto initialization documentation](https://matrix-org.github.io/matrix-js-sdk/classes/matrix.MatrixClient.html#initRustCrypto) supplies its persistence defaults. OpenStreetMap's [standard tile policy](https://operations.osmfoundation.org/policies/tiles/) restricts bulk and offline downloading; a map library license is not a tile-service license.

## Fourteen useful differentiators

These are proposed product directions, not fourteen completed features. Several extend existing safeguards. None is a prediction that Sakhi can prevent violence.

| Direction | User value and reuse | Safe scope |
| --- | --- | --- |
| Preventive learning entrance | A short public learning library for people exploring digital privacy, consent or available support before a specific concern. Use the existing public pack and accessible disclosures. | General reviewed information, without personal risk scores or mandatory quizzes. |
| Concern entrance with minimum disclosure | Let someone choose an outcome and topic without narrating an incident. Improve the existing stepper with editable choices and clear return points. | Emergency choice bypasses all retrieval; unsupported minor workflows stop. |
| Equal-weight next steps | Compare learning, general support and official reporting without visually pushing a complaint. Accessible cards and optional comparison controls. | Descriptions reflect reviewed official scope; no personalized legal recommendation. |
| Source receipts people can understand | Explain authority, jurisdiction, last check, expiry and what the source cannot establish. Reuse current receipts and HSDS relationships. | Link health and human verification stay separate. |
| Visible stale-pack recovery | Show when only a dated general fallback is available, including after an offline reload. Extend current TTL behavior. | Do not imply current service capacity, call connectivity or complaint acceptance. |
| Device-risk choices before disclosure | Let people skip free text, review what a destination receives, and clear the session without resurfacing pending results. | No stealth or complete-history-erasure promise. |
| Script-aware reading mode | Comfortable Indic line spacing, font selection, numerals and RTL controls, with a simpler reading layout. | Physical-device and native-language review precede verification claims. |
| Public-only offline learning | A versioned pack with general cards and essential public sources, usable without a model or account. | No private answers, drafts or API results enter the cache. |
| A trusted-helper entrance | Let a friend find public resources without entering another person's details. Extend current helper routing. | Bystander scripts require expert review; do not instruct confrontation or impersonation. |
| Accessibility details before a map | When individually sourced, show language, communication channel and accessibility information alongside district filters. | Unknown accessibility stays unknown; no invented addresses or safe-route labels. |
| Community corrections with a receipt | A public correction can show proposed change, authoritative evidence, reviewer and accepted content version. Build on issue templates and read-only maintenance. | Never submit personal cases to GitHub. No automatic publication or majority vote on safety content. |
| Translation contributions with clear limits | Volunteers propose UI wording while named language and safeguarding reviewers approve scoped releases. Existing review stamps remain visible. | A merged translation pull request does not automatically certify advice. |
| A comprehensible retrieval explanation | Explain that a selected topic or public keyword led to these resources, with an easy option to change course. | Do not store query explanations or expose a numeric score as safety or legal confidence. |
| An inspectable public-benefit release | Publish nonsensitive source changes, dependencies, language coverage, accessibility evidence and remaining limits. Chayn's contribution model is a useful reference. | Community participation does not authorize real provider handoffs or claim institutional endorsement. |

## Model and safeguarding limits

Keep EmbeddingGemma 2 optional and outside emergency, minor, consent and factual-contact decisions. Google's [model card](https://ai.google.dev/gemma/docs/embeddinggemma/model_card_2) identifies it as an embedding model under Apache-2.0, not a generative counsellor. Sakhi's existing local benchmark is draft and in-sample: English has 44 cases and each other locale only four. Hybrid top-one agreement was lower than lexical top-one agreement in several locales. That does not establish a reason to promote semantic ranking to the default. Create held-out human-reviewed retrieval labels and compare errors by locale before changing routing policy.

[Transformers.js](https://github.com/huggingface/transformers.js) runs supported models through ONNX Runtime, but a compatible, evaluated browser export of this exact pinned EmbeddingGemma 2 model has not been established here. Its documented defaults can load remote models and CDN WASM. A future browser spike must explicitly disable remote models, self-host its runtime assets, avoid sensitive cache entries and measure memory on low-end devices. Do not move the current roughly 1.53 GB local model cache into normal page loading.

NNEDV Safety Net's [digital-service principles](https://www.techsafety.org/best-practice-principles) and [advocate communication guidance](https://www.techsafety.org/online-communication-for-advocates) support minimal collection, clear service limits, informed choices and attention to conversation histories. They are specialist guidance, not a software license, Indian legal advice or institutional approval. Link and summarize cautiously; do not copy entire toolkits or import US hotline and legal instructions into Indian flows. Chayn is a relevant survivor-support design reference, not an authorization to provide therapy or reuse its service claims.

Keep personalized escape planning, diagnosis, suspect scoring, ambient listening, precise tracking, automated police contact, unofficial messaging bots and automated government forms out of this sprint. Even general preventive modules need qualified safeguarding and language review before public release. An encrypted message can still reveal notifications, account metadata, recipients and local records. A Matrix event receipt would not prove a human provider accepted a referral.

## Recommended next implementation choices

1. Extend the local public learning and concern journeys using existing components. Spike one complex React Aria control and compare keyboard, TalkBack/VoiceOver, RTL, 320-pixel layout and bundle cost against the native control before choosing a dependency.
2. Add self-hosted fonts for a small reviewed script set, then expand using complete shaping specimens and per-locale acceptance checks. Review built-in widget announcements separately from Sakhi's catalogs.
3. Replace the HSDS-inspired claim with a genuinely validated, clearly scoped export, including real organization relationships and stable identifiers. Keep original source rights, dates and review states intact.
4. Benchmark a public-content MiniSearch prototype only if the learning library justifies browser search. Preserve deterministic routes and compare with current SQLite and conservative abstention.
5. Keep maps, private storage and messaging disabled until their data, provider, security and safeguarding prerequisites exist. Record a concrete integration contract before adding their SDKs.

The current release verdict remains `internal_demo_only`. Richer UX and selected open-source reuse do not close the existing human safeguarding, contact verification, language, physical-device or independent security gates.
