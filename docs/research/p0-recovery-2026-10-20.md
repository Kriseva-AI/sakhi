# P0 recovery source and tool decisions

Checked 2026-10-20. Public pages only, no private story, login, person contact or message. Source inspection does not establish real-time service reachability. Original Sprint 2 research remains historical evidence.

| Primary source | Observation and engineering use |
| --- | --- |
| [MWCD Child Helpline](https://wcd.gov.in/child/child-helpline) | Specific official 1098 information replaces the generic ministry homepage. Child support stays deterministic; no adult form or imagery intake. |
| [MWCD Women Helpline](https://wcd.gov.in/women/help) | West Bengal exception remains explicit; no local 181 availability promise there. |
| [NCMEC Take It Down FAQ](https://takeitdown.ncmec.org/faq/) | Image age matters even for an adult now. Do not obtain/forward an image to use the tool. Coverage is participating platforms. Conditional information only. |
| [StopNCII](https://stopncii.org/) | Adult-now/adult-at-image criteria, possession and image subject must be checked with the provider. Unknown age does not become eligibility. |
| [Indian cybercrime portal](https://cybercrime.gov.in/) | Direct research fetch failed. Retain official entry with an honest availability limit; do not promise anonymous reporting for all categories. Existing official manual/reference supports the entry. |
| [NNEDV quick-exit guidance](https://www.techsafety.org/exit-from-this-website-quickly) | Screen change does not erase history or device monitoring. Local cover and explicit external exit have different effects. No history-erasure promise. |
| [WhatsApp click to chat](https://faq.whatsapp.com/5913398998672934) | Exact international-number link and neutral message can open a draft. Account/recipient validity and actual sending remain in the recipient app. No API authorization inferred. |
| [WhatsApp live location](https://faq.whatsapp.com/480865177351335/) | Recipient/duration/Send and Stop sharing are separate user decisions. Last shared point may remain visible. Native-app assistance cannot be represented as Sakhi observing live delivery. |
| [Safetipin help](https://safetipin.com/my-safetipin-app-help/) | Comparator uses its own audited/crowdsourced infrastructure observations. That does not give Sakhi a dataset, reuse right or validated safety score. No crime zones copied/generated. |
| [Leaflet upstream](https://github.com/Leaflet/Leaflet), [Nominatim upstream](https://github.com/osm-search/Nominatim) | Rechecked maintained project pages. Retain installed Leaflet and accessible list. Switching geocoders would not solve POI capacity or contact verification. No new dependency installed. |

## Decision matrix

| Choice | Benefit | Limitation | Decision |
| --- | --- | --- | --- |
| Existing Vite/React + FastAPI/local retrieval | No keys; working emergency/offline core; existing regression suite | Needs human acceptance and hosting review | Retain |
| New framework or map SDK | Possible new controls | Migration cost does not resolve source/permission blockers | Reject this sprint |
| Community Overpass with bounded wait + manual public-map alternative | Honest usable recovery without invented facilities | No production SLA, verified provider coverage or automatic host switching | Internal preview only; capacity blocker open |
| WhatsApp recipient/content preview | Useful chosen-person update with no account integration | Sakhi cannot observe Send/delivery/acknowledgement | Explicit handoff; user records labelled self-reported |
| Browser foreground location | Local actual location/accuracy reading, separately chosen one-time snapshot | OS/network accuracy, background and recipient privacy limits | Optional; never starts at load; separate sharing approval |
| Reasoning model default | Potential broader language understanding | Current new English holdout underperforms deterministic baseline; no expert gold | Do not promote |

## New frozen model comparison

Fixture `data/synthetic/heldout-routing-2026-10-20.json` was frozen before generation and never used as prompt examples or for tuning. Local Ollama executed installed Gemma3 4B and Qwen3.5 9B quantizations; no weights downloaded or user text sent. Exact fixture/prompt hashes, per-case labels/outputs and timings: `evidence/continuation/heldout-models.json`.

16 English synthetic cases: local deterministic/lexical 16/16, Gemma 13/16, Qwen 14/16. Median classification latency was below timer resolution for local rules, 431ms Gemma and 491.5ms Qwen on this Mac. Gemma missed workplace/home/friend cases; Qwen missed cyber/friend cases. The sample is small, author-labelled and not independently expert-reviewed. This is route classification evidence, not broad reasoning, safety or multilingual validation. No runtime policy was tuned to the holdout and no production accuracy claim is permitted. All 16 locales retain the existing human and held-out multilingual gates.
