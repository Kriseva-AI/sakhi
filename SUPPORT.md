# Support

This project provides software and public information navigation. It is not a police, legal, medical or counselling service and has no guaranteed monitoring. For immediate danger in India, call 112 if possible. Child Helpline 1098 and Women Helpline 181 are public options with provider-specific scope; 181's official page lists a West Bengal exception.

Use public software issues only after publication and only with synthetic reproductions. Never include private case details. Setup problems belong in a bug report with OS, runtime version and nonsensitive error output. Source corrections use the public resource template and remain pending until reviewed.
